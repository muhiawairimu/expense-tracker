# 📊 Personal Expense & Budget Dashboard

An interactive, responsive financial management dashboard built with HTML5, CSS3, JavaScript, and Chart.js. Track income and expenses, monitor category spending with dynamic data charts, and set budget limits.

---

## ✨ Features

- **Financial Metrics Overview:** Real-time calculation of total balance, income, and expenses.
- **Dynamic Budget Tracker:** Progress bar with automated color alerts (Green <75%, Orange 75–90%, Red >90%).
- **Interactive Visual Analytics:** Powered by Chart.js (Doughnut category breakdown + Bar income vs. expense chart).
- **Filtering & Search:** Live keyword search and category/type filter options.
- **CSV Data Export:** Single-click export of transactions to a `.csv` file.
- **Local Persistence:** Data persists locally in the browser using `localStorage`.
